To add a new entity:

In the C:\Users\EricOwens\Desktop\AI\playground\ folder there are three sub-folders:
- RanchRewrites
- SaveRanchRewrites
- InspectRanchRewrites

Copy the Ranch folder in SaveRanchRewrites to RanchRewrites.

Open the CsharpRanchRewriter project in Visual Studio. 
At the top of the Program.cs file, change the value of 
- upperCaseReplacement and
- lowerCaseReplacement 
to the name for the new entity.

Run the CsharpRanchRewriter project.

The project will create all of the necessary files for the new entity in the WebApi,
move those files to the actual project, and then update other files in the project.

When this is complete, navigate to
~/Desktop/AI/randomRanch/dotnet-starter-kit/src/api/server

NOTE:  If something goes wrong and the CsharpRanchRewriter needs updating, be sure to git restore the original versions of the RandomRanch files and to
copy the Ranch folder in SaveRanchRewrites to RanchRewrites again.

and run the following commands:
 dotnet ef migrations add "Add [New Entity Name] to Ranch Schema" --project .././migrations/postgresql/ --context RanchDbContext -o Ranch
 dotnet ef database update --project .././migrations/postgresql/ --context RanchDbContext

When this is complete, run the RandomRanch solution Host.  The host will launch Swagger.

Now, navigate to ~/Desktop/AI/nswag and run the following command:
 nswag run nswag.json

 This will create a new version of the ApiClient.cs file in ~/Desktop/AI/nswag.
 Copy this ApiClient.cs file to
 C:\Users\EricOwens\Desktop\AI\randomRanch\dotnet-starter-kit\src\apps\blazor\infrastructure\Api,
 replacing the existing ApiClient.cs file already there.

 Now, in the Blazor project,
